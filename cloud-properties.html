Cloud property retrieval from hyperspectral images

These figures and images show the retrieval of various cloud properties from measured hyperspectral images using radiative transfer modelling

Image below shows the retrived cloud top height (CTH) from radiative transfer modelled absorption depth of the oxygen A band at various cloud top altitudes, displayed CTH obtained from linear interpolation of model.

Below is a modelled output look up table of the cloud droplet effective radius and cloud optical thickness. The radiance of these channels is coupled and must be calculated pairwise for the microphysical properties.

The image below shows the cloud optical thickness retrived by matching the measured radiances of each pixel to the nearest vertex on the lookup table able.
