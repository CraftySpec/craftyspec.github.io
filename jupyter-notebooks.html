➤ Cloud Micro-physics Retrieval

This notebook performs radiative transfer calculations for specific hyperspectral images of clouds. It calculates cloud top height and temperature by comparing the observed absorption depth of the oxygen A-band near 760 nm to simulated absorptions at specific surface heights. These data are used as inputs for a second set of radiative transfer calculations that calculate cloud optical thickness (τ) and effective cloud droplet radius (re).
